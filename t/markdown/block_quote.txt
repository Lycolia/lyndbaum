=== 引用
--- input
> 引用文
--- expected
<blockquote>
引用文
</blockquote>

=== 複数行の引用
--- input
> 1行目
> 2行目
--- expected
<blockquote>
1行目<br />
2行目
</blockquote>

=== 引用の入れ子
--- input
> 外
> > 内
--- expected
<blockquote>
外
<blockquote>
内
</blockquote>
</blockquote>

=== 引用内のリスト
--- input
> - a
> - b
--- expected
<blockquote>
<ul>
<li>a</li>
<li>b</li>
</ul>
</blockquote>

=== 非対応: >の無い継続行は引用の外
--- input
> a
b
--- expected
<blockquote>
a
</blockquote>
<p>b</p>

=== 引用の直後の、> の無いリストは引用の外
--- input
> a
- b
--- expected
<blockquote>
a
</blockquote>
<ul>
<li>b</li>
</ul>

=== 引用の直後の、> の無いコードフェンスは引用の外
--- input
> a
```
code
```
--- expected
<blockquote>
a
</blockquote>
<pre><code class="language-">code
</code></pre>

=== > の無いコメントだけの行では引用を分けない
--- input
> a
<!-- c -->
> b
--- expected
<blockquote>
a<br />
b
</blockquote>
