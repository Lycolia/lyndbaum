=== コードフェンス（言語あり）
--- input
```perl
my $a = 1;
```
--- expected
<pre><code class="language-perl">my $a = 1;
</code></pre>

=== コードフェンス（言語なし）
--- input
```
text
```
--- expected
<pre><code class="language-none">text
</code></pre>

=== コード内のHTMLはエスケープ
--- input
```
<b>&amp;</b>
```
--- expected
<pre><code class="language-none">&lt;b&gt;&amp;amp;&lt;/b&gt;
</code></pre>

=== 4つのバッククォートで中に```を含める
--- input
````md
```
code
```
````
--- expected
<pre><code class="language-md">```
code
```
</code></pre>

=== 非対応: インデントのコードブロックは文章
--- input
前

    code

後
--- expected
<p>前</p>
<p>code</p>
<p>後</p>

=== 非対応: ~~~ のフェンスは文章
--- input
~~~
code
~~~
--- expected
<p>~~~<br />
code<br />
~~~</p>

=== 非対応: math のフェンスは普通のコードブロック
--- input
```math
x^2
```
--- expected
<pre><code class="language-math">x^2
</code></pre>

=== 非対応: 字下げしたフェンスは文章
--- input
   ```
   code
   ```
--- expected
<p>```<br />
code<br />
```</p>

=== 非対応: リストの項目の中の ~~~ も文章
--- input
- a
  ~~~
  code
  ~~~
--- expected
<ul>
<li>a<br />
~~~<br />
code<br />
~~~</li>
</ul>

=== 非対応: 4スペースで字下げしたフェンスは文章
--- input
前

    ```
    code
    ```
--- expected
<p>前</p>
<p>```<br />
code<br />
```</p>

=== 非対応: リストの項目の中で深く字下げした行は文章
--- input
- a

      深い字下げ
--- expected
<ul>
<li><p>a</p>
<p>深い字下げ</p></li>
</ul>

=== 言語は最初の語だけを使う
--- input
```js title
code
```
--- expected
<pre><code class="language-js">code
</code></pre>

=== フェンスと言語の間の空白は無視する
--- input
``` js
code
```
--- expected
<pre><code class="language-js">code
</code></pre>

=== 非対応: 言語:ファイル名 のファイル名は使わない
--- input
```js:a.js
code
```
--- expected
<pre><code class="language-js">code
</code></pre>
