# テーブルと列

DBのテーブルと列の一覧と、それぞれの役割。テキストDBでのファイルの置き方は`テキストDB.md`を参照。

## 定義の場所

| テーブル                                                  | 定義                                                                         |
| --------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `art`、`tag`、`tagart`、`com`、`rev`、`link`、`trash`、`trashcom` | `lib/SatsukiApp/adiary_5.pm`の`create_tables`（`art_table_info`、`com_table_info`など） |
| `_users`、`_users_sid`、`_users_log`                      | `lib/Satsuki/Auth_3.pm`の`create_user_table`                                 |

- ユーザーのテーブル名は`info/lyndbaum.conf.cgi`の`Auth.table`（既定は`_users`）。`_sid`と`_log`は、その名前の後ろに付けたもの。
- 既にあるブログに列を足すときは、`lib/SatsukiApp/adiary_6.pm`のアップデート処理（`sys_update_*`）で`add_column`する（`アップデート処理.md`）。`art`と`com`に足すときは、`trash`と`trashcom`にも同じ列を足す。

## 型と制約の書き方

この文書の表では、定義（`create_table_wrapper`に渡すハッシュ）を次のように書く。

| 表記   | 定義のキー | 意味                                                                   |
| ------ | ---------- | ---------------------------------------------------------------------- |
| text   | `text`     | 文字列                                                                 |
| ltext  | `ltext`    | 長い文字列（本文など）                                                 |
| int    | `int`      | 整数                                                                   |
| flag   | `flag`     | 0か1                                                                   |
| idx    | `idx`      | indexを張る                                                            |
| idx(T) | `idx_tdb`  | indexを張る（`idx`と同じ。ほかのDBがあったころ、テキストDBのときだけ張るために分けていた） |
| uniq   | `unique`   | 重複を許さない                                                         |
| NN     | `notnull`  | 空を許さない                                                           |
| →      | `ref`      | 参照先（外部キー）                                                     |

- `pkey`はどのテーブルにも必ずある、1から順に振る整数の主キー。表には書かない。
- 時刻の列（`tm`、`update_tm`、`login_tm`など）は、どれもUNIX時間（秒）。日付の列（`yyyymmdd`、`a_yyyymmdd`）だけは`20261028`のような8桁の整数。

## テーブルの一覧

| テーブル     | 役割                                                       |
| ------------ | ---------------------------------------------------------- |
| `art`        | 記事とページ（コンテンツ）                                 |
| `tag`        | タグ                                                       |
| `tagart`     | 記事とタグの結び付き                                       |
| `com`        | コメント                                                   |
| `rev`        | 記事の更新履歴（変更前の版）                               |
| `link`       | 記事から、ブログ内のほかの記事へのリンク（参照元を作る元） |
| `trash`      | ゴミ箱に入れた記事                                         |
| `trashcom`   | ゴミ箱に入れた記事のコメント                               |
| `_users`     | ユーザー                                                   |
| `_users_sid` | ログイン中のセッション                                     |
| `_users_log` | ログインなどの操作の記録                                   |

## art（記事とページ）

ブログの記事と、ページ（コンテンツ、wiki）を同じテーブルに入れる。`ctype`が空なら記事、空でなければページ。

| 列            | 型    | 制約          | 役割                                                                                                                                                         |
| ------------- | ----- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `title`       | text  | idx(T)        | 題名。空で保存すると日付（`2026-10-28`）になる                                                                                                               |
| `parser`      | text  |               | 本文の記法の名前。空なら記法を通さず、`_text`をそのままHTMLにする                                                                                            |
| `tags`        | text  | idx(T)        | タグの名前を`,`でつないだもの。`tagart`と同じ中身を、記事だけで読めるように持つ                                                                             |
| `name`        | text  | idx           | 書いた人の表示名。新しく作ったときだけ入れる                                                                                                                 |
| `id`          | text  | idx           | 書いた人のユーザーID。新しく作ったときだけ入れる。「自分の記事だけ編集できる」設定（`edit_by_author_only`）で使う                                           |
| `ip`          | text  |               | 投稿したときの接続元のIPアドレス。新しく作ったときだけ入れる。編集画面と書き出しで使う                                                                       |
| `host`        | text  |               | 投稿したときの接続元のホスト名。IPv6のときは空                                                                                                               |
| `agent`       | text  |               | 投稿したときのUser-Agent                                                                                                                                     |
| `link_key`    | text  | idx、uniq、NN | URLになるkey。記事は`0`+`pkey`（例：`0815`）、ページは入力したkey                                                                                            |
| `ctype`       | text  | idx           | 種類。空は記事、`wiki`はページ                                                                                                                               |
| `main_image`  | text  |               | 代表画像（OGPの画像）。画像のフォルダからのパス。`?幅,高さ`が付くことがある。`?none`は「設定しない」で、本文の画像を拾わずにブログの画像を使う               |
| `description` | text  |               | 説明文（OGPのdescription）。本文からタグを除き、`desc_len`（既定64）文字に切ったもの                                                                         |
| `backlinks`   | text  |               | 参照元（この記事にリンクしている記事）の一覧のHTML（`<li>`の並び）。`update_backlinks`が`link`から作る。ページでは空                                        |
| `text`        | ltext |               | 本文のHTML（記法を通し、許可していないタグを除いたもの）                                                                                                     |
| `text_s`      | ltext |               | 一覧に出す短い本文のHTML（「続きを読む」より前）。`text`と同じなら空                                                                                         |
| `_text`       | ltext |               | 本文の元の文章（記法で書いたもの）。編集画面にはこれを出す                                                                                                   |
| `yyyymmdd`    | int   | idx、NN       | 記事の日付。編集画面で選んだ日付で、URLの日付や一覧の並びに使う                                                                                              |
| `tm`          | int   | idx           | 下書きでなくなった（公開か非公開で初めて保存した）日時。空なら下書き |
| `update_tm`   | int   | idx           | 最後に更新した日時。「更新日時を変えない」で保存すると変わらない                                                                                             |
| `coms`        | int   | idx、NN       | 表示しているコメントの数（`com.enable`が1のもの）。`calc_comments`が数え直す                                                                                 |
| `coms_all`    | int   | idx、NN       | 非表示も含めた、すべてのコメントの数                                                                                                                       |
| `upnode`      | int   | idx           | ページの親のページの`pkey`。記事では空                                                                                                                       |
| `priority`    | int   | idx           | ページの並び順（小さいほど前）。記事では0                                                                                                                    |
| `enable`      | flag  | idx、NN       | 公開しているか。0は非公開で、編集できる人にだけ見える                                                                                                        |
| `com_ok`      | flag  | NN            | コメントを受け付けるか                                                                                                                                       |
| `nsfw`        | flag  |               | NSFWの記事か。閲覧画面で、年齢の確認をするまで本文を隠し、代表画像も出さない |

- 読み込んだときに、`yyyymmdd`から`year`、`mon`、`day`、`wday_name`を、`update_tm`から`upd_year`などを、`link_key`からURL用の`elink_key`を、`tm`から`draft`（下書きか）を作る（`post_process_article`）。これらは列ではない。
- 本文か題名を変えて保存すると、変える前の版を`rev`に入れる。
- 記事を非公開にする、または題名、日付、`link_key`を変えると、その記事のコメントの`enable`、`a_title`、`a_yyyymmdd`、`a_elink_key`も書き換える。

## tag（タグ）

`aaa::bbb`のような階層のあるタグは、`aaa`と`aaa::bbb`の2行になり、`aaa::bbb`の`upnode`が`aaa`を指す。

| 列         | 型   | 制約          | 役割                                                                                 |
| ---------- | ---- | ------------- | ------------------------------------------------------------------------------------ |
| `name`     | text | idx、uniq、NN | タグの名前。階層は`::`でつないだ全体（例：`aaa::bbb`）                               |
| `qt`       | int  | idx、NN       | このタグが付いた公開中の記事の数。`update_taglist`が`tagart`から数え直す             |
| `upnode`   | int  | idx、→tag     | 親のタグの`pkey`。いちばん上のタグでは空                                             |
| `priority` | int  | idx、NN       | 並び順（小さいほど前）。新しく作ったタグは`default_tag_priority`（100000）           |

- タグの一覧は、このテーブルから`tag_cache.txt`（ブログのフォルダ）と`taglist.json`を作って使う。子のタグを含めた数（`qtall`）は、そのときに数える。

## tagart（記事とタグの結び付き）

記事1件に付いたタグ1つごとに1行。記事のタグを変えると、その記事の行を消して入れ直す。

| 列         | 型   | 制約          | 役割                                                                 |
| ---------- | ---- | ------------- | -------------------------------------------------------------------- |
| `a_pkey`   | int  | idx、NN、→art | 記事の`pkey`                                                         |
| `t_pkey`   | int  | idx、NN、→tag | タグの`pkey`                                                         |
| `a_enable` | flag | idx、NN       | 記事が公開しているか（`art.enable`の写し）。`tag.qt`を数えるのに使う |

## com（コメント）

| 列            | 型   | 制約          | 役割                                                                                                 |
| ------------- | ---- | ------------- | ---------------------------------------------------------------------------------------------------- |
| `text`        | text | NN            | 本文。タグを無効にし、改行を`<br>`にしたもの                                                         |
| `email`       | text |               | 書いた人のメールアドレス（任意）。編集できる人にだけ見える                                           |
| `url`         | text |               | 書いた人のURL（任意）。`http(s)://`で始まるものだけ                                                  |
| `name`        | text | idx           | 書いた人の名前。ログイン中ならユーザーの表示名                                                       |
| `id`          | text | idx           | 書いた人のユーザーID。ログインしていなければ空。管理者の印（`by_admin`）を付けるのに使う             |
| `ip`          | text | idx(T)        | 接続元のIPアドレス。スパム対策と、編集できる人への表示に使う                                         |
| `host`        | text |               | 接続元のホスト名。IPv6のときは空                                                                     |
| `agent`       | text |               | User-Agent                                                                                           |
| `a_title`     | text |               | 記事の題名の写し。新着コメントの一覧などで、記事を読まずに出すため                                   |
| `a_elink_key` | text |               | 記事のURL用のkey（`elink_key`）の写し                                                                |
| `tm`          | int  | idx、NN       | 書いた日時                                                                                           |
| `num`         | int  | idx(T)        | 記事の中でのコメントの番号（1から）。表示の`#c番号`に使う。空なら`calc_comments`が振る               |
| `a_pkey`      | int  | idx、NN、→art | コメントした記事の`pkey`                                                                             |
| `a_yyyymmdd`  | int  | idx(T)、NN    | 記事の日付の写し                                                                                     |
| `enable`      | flag | idx、NN       | 公開の画面に出すか。承認済み（`hold`が1でない）で、記事が公開のときだけ1。0のものは編集できる人にだけ見える |
| `hold`        | flag |               | 承認待ちか。1なら承認待ち。空か0なら承認済み（4.18で足した列で、それより前のコメントは空）           |

- `a_`で始まる列は、記事の値を写したもの。記事の側を変えると書き換える（`art`の節）。
- 記事の`coms`と`coms_all`は、コメントを書いたり消したりするたびに`calc_comments`が数え直す。
- `hold`はコメントそのものの状態、`enable`はそれと記事の公開から決まる表示。投稿で保留したとき（`defer_com`、スパム対策の承認待ち）と「承認を取り消す」で`hold`を1に、「承認」で0にする。
- 記事を非公開にすると、その記事のコメントの`enable`を0にする（`hold`は変えない）。公開に戻すと、`hold`が1でないものの`enable`を1に戻す。
- `enable`が1で`hold`が1の組み合わせは作らない。最近のコメントやブログのコメント数など、公開の画面は`enable`だけを見るため。

## rev（記事の更新履歴）

記事の本文か題名を変えたときに、変える前の版を入れる。記事を消しても残す（ゴミ箱から戻したときに使う）ので、記事への参照は張らない。

| 列          | 型    | 制約    | 役割                                                       |
| ----------- | ----- | ------- | ---------------------------------------------------------- |
| `title`     | text  |         | その版の題名                                               |
| `_text`     | ltext |         | その版の本文の元の文章                                     |
| `a_pkey`    | int   | idx、NN | 記事の`pkey`                                               |
| `tm`        | int   | idx、NN | 履歴に入れた日時                                           |
| `update_tm` | int   |         | その版を保存した日時（`art.update_tm`、空なら`art.tm`）    |

- 前に入れてから`rev_cycle`分（既定180）の間は入れない（続けて保存したものを1つの版にまとめる）。
- 1つの記事で`rev_max`（既定120）を超えたら、古いものから消す。どちらもブログの設定で、0なら制限しない。

## link（記事のリンク）

記事の本文にある、ブログ内のほかの記事へのリンク1つごとに1行。参照元（`art.backlinks`）を作るのに使う（`update_backlinks`）。

| 列         | 型   | 制約    | 役割                                                       |
| ---------- | ---- | ------- | ---------------------------------------------------------- |
| `link_key` | text | idx、NN | リンク先の記事の`link_key`。まだ無い記事のものも持っておく                                                    |
| `a_pkey`   | int  | idx、NN | リンク元の記事の`pkey`                                     |

- 記事を消した後に行を消すので、記事への参照は張らない。

## trash、trashcom（ゴミ箱）

記事を消すと、記事を`trash`に、その記事のコメントを`trashcom`に移す。`pkey`は元の記事やコメントのものをそのまま使う（`pkey`は使い回さないので、元に戻せる）。

- `trash`の列は`art`と同じで、次の2つが加わる。

| 列           | 型   | 制約 | 役割                       |
| ------------ | ---- | ---- | -------------------------- |
| `deleted_tm` | int  | idx  | ゴミ箱に入れた日時         |
| `deleted_id` | text |      | ゴミ箱に入れたユーザーのID |

- `trashcom`の列は`com`と同じ。
- 同じ`link_key`の記事を何件も入れられるよう、uniqと参照は付けない。indexは`trash`が`id`と`deleted_tm`、`trashcom`が`a_pkey`だけ。

## _users（ユーザー）

| 列         | 型   | 制約          | 役割                                                                         |
| ---------- | ---- | ------------- | ---------------------------------------------------------------------------- |
| `id`       | text | idx、uniq、NN | ログインに使うID                                                             |
| `name`     | text | NN            | 表示名                                                                       |
| `pass`     | text |               | パスワードのハッシュ。`*`ならパスワードではログインできない                  |
| `email`    | text | idx、uniq     | メールアドレス                                                               |
| `login_c`  | int  |               | ログインした回数                                                             |
| `login_tm` | int  |               | 最後にログインした日時                                                       |
| `fail_c`   | int  |               | 続けてログインに失敗した回数。`fail_count`回を超えるとしばらくログインできない |
| `fail_tm`  | int  |               | 最後にログインに失敗した日時。`fail_minute`分たつと`fail_c`を0から数え直す   |
| `disable`  | flag |               | 無効にしたユーザーか                                                         |
| `isadmin`  | flag | idx           | システムの管理者か                                                           |

- 本人が変えられるのは`name`と`email`だけ（`allow_user_change_columns`）。

## _users_sid（セッション）

ログインするたびに1行入れ、ログアウトや期限切れで消す。

| 列         | 型   | 制約              | 役割                       |
| ---------- | ---- | ----------------- | -------------------------- |
| `id`       | text | idx、NN、→_users  | ユーザーのID               |
| `sid`      | text | idx、NN           | セッションID（32文字）     |
| `login_tm` | int  | idx、NN           | ログインした日時。有効期限はここから数える |

## _users_log（操作の記録）

| 列      | 型   | 制約    | 役割                                                                                               |
| ------- | ---- | ------- | -------------------------------------------------------------------------------------------------- |
| `id`    | text | idx     | ユーザーのID。ログインの失敗では、入力されたIDをそのまま入れる（無いIDも入れるので、参照は張らない） |
| `type`  | text | idx     | 操作の種類。`login`、`logout`、`regist`（追加）、`update`（変更）、`delete`（削除）                |
| `msg`   | text |         | 補足。失敗したときの`fail`など                                                                     |
| `ip`    | text | idx     | 接続元のIPアドレス                                                                                 |
| `host`  | text |         | 接続元のホスト名                                                                                   |
| `agent` | text |         | User-Agent                                                                                         |
| `tm`    | int  | idx、NN | 操作した日時                                                                                       |
