# サイドバーの引き出し

狭い画面で、サイドバーを画面の端から出る引き出しにし、画面の角のボタンで開く。開け閉めの仕組みは共通（`tools/js/src/adiary.js`の「サイドバーの引き出し」、`pub/assets/theme/base.css`）で、どの幅で、どの要素を、どちら側から出すかはテーマのCSSが決める。

## マークアップ

| 要素 | 書き方 |
| --- | --- |
| ボタン | `<button type="button" class="sidebar-toggle …" aria-controls="引き出しのid" aria-expanded="false" aria-label="…">`。`hidden`は付けない（出すかどうかはCSS） |
| 引き出し | `aria-controls`のidを持つ要素 |

- 標準の雛形（`#sidebar`を持つテーマ。satsuki2系）は、`skel/_frame.html`がヘッダーの後に`#sidebar`を開くボタン（`.sidebar-toggle-menu`）を1つ置く
- 自分の雛形を持つテーマは、雛形にボタンを置く（lyndbaumは`_skel/_header.html`に3つ。3カラムのテーマはAとBを別々に開く左右の2つを使い、2カラムのテーマはAとBの包み`#sidebars`を開く三本線の1つを使う）。`#sidebar`が無ければ、`_frame.html`のボタンは出ない

## クラスとCSSの変数

| 名前 | 付ける所 | 意味 |
| --- | --- | --- |
| `has-drawer` | `html` | JavaScriptが使えるとき。`_frame.html`の`<head>`で、本文を描く前に付ける（表示した後にサイドバーが消えて、ずれないように）。付いていないときは、引き出しにしない |
| `is-open` | 引き出し | 開いている |
| `drawer-open` | `html` | 開いている間。本文のスクロールを止める（`base.css`） |
| `drawer-keep-gutter` | `html` | 開いたときにスクロールバーがあった。その幅を残す（`base.css`） |
| `drawer-animate` | `html` | 動きを付けてよいとき。読み込んだ直後と、幅を変えている間は外す |
| `.drawer-backdrop` | `body`の最後 | 暗幕。JavaScriptが作る。押すと閉じる |
| `--drawer: 1` | 引き出し | テーマのCSSが、引き出しになっている幅でだけ付ける。幅が変わってこの値が無くなったら、開いていても閉じる |
| `--drawer-target: id` | ボタンの`aria-controls`の要素 | ボタンが開く要素を、別の要素に変える（wpは、狭い画面で`#sidebar`の代わりに`#side-a`を開く） |
| `--drawer-bg`、`--drawer-fg` | `html` | 引き出しとボタンの地の色と文字の色。テーマが決めなければ、JavaScriptが本文の地の色（引き出しの親を辿って最初に見つかった背景の色）と、引き出しの文字の色を入れる |

## 動き

- ボタンを押すと開き、もう一度押すと閉じる。暗幕を押したとき、`Esc`キーを押したときも閉じる
- 開くと、ボタンに`aria-expanded="true"`を付ける。閉じると、ボタンにフォーカスを戻す
- 引き出しのリンクで移ってから戻ったとき（bfcache）は、閉じておく
- JavaScriptが使えないときは、ボタンを出さず、サイドバーは引き出しにしない

## テーマの側で書くこと

- 引き出しにする幅の`@media`の中で、`.has-drawer 引き出し`に、置き方（`position: fixed`、幅、出る側への`transform`、`visibility: hidden`）と`--drawer: 1`を書く
- `.has-drawer 引き出し.is-open`で、`transform`と`visibility`を戻す
- 動きは`.drawer-animate 引き出し`に書く。`prefers-reduced-motion: reduce`のときは付けない
- ボタンは`.has-drawer .ボタンのクラス`で出す
- 標準の雛形のテーマは、`base.css`が640px以下で`#sidebar`を右から出る引き出しにするので、書かなくてよい。変えたいときだけ、テーマのCSSで上書きする
