# 書式

`x.y.z-a`

# 意味合い

| 位置 | 意味合い | 上げる基準                                 |
| ---- | -------- | ------------------------------------------ |
| x    | major    | メジャーバージョンアップ、基準は未定       |
| y    | minor    | データマイグレーションが必要な更新         |
| z    | patch    | データマイグレーションが不要なすべての更新 |
| a    | branch   | fix2、dev3、nightlyなど、特に決まりはない  |
