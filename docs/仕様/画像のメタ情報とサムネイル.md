# 画像のメタ情報とサムネイル

## アップロードした画像のメタ情報

メディアに画像を上げると、保存する前に、撮影情報（Exif）と表示に要るもの以外のメタ情報を消す（`Satsuki::ImageMeta`）。再編集用のデータや、機種独自のデータは、ブログでは使わないため。

画像のデータは読み直さず、セグメントやチャンクを選んでつなぎ直す。画質は変わらない。

| 形式 | 消すもの | 残すもの |
|---|---|---|
| JPEG | XMP、拡張XMP（ぼかし写真の、ぼかす前の画像や深度マップなど）、APP3〜APP13・APP15（機種独自の情報）、APP1・APP2のその他（Flashpixなど）、コメント、画像の後ろの余分なデータ | Exif、JFIF、ICCプロファイル、Adobe（APP14）、MPFと、MPFが指す2枚目以降の画像（Ultra HDRのゲインマップなど）、ゲインマップの情報を持つXMP（`hdrgm`） |
| PNG | XMP（`iTXt`の`XML:com.adobe.xmp`）、`IEND`の後ろのデータ | Exif（`eXIf`）、文字の情報（`tEXt`・`zTXt`・`iTXt`。ComfyUIの生成情報やdraw.ioの編集データ）、色の情報 |
| WebP | XMP | Exif、ICCプロファイル |

- GIFとAVIFは触らない
- MPFより後ろのセグメントを消すと、2枚目以降の画像までの距離が縮むので、MPFの中の位置と大きさを直す。MPFが読めない画像は、何も変えない
- 同じ名前の画像をもう一度上げたときの「中身が同じなら今のファイルを使う」は、メタ情報を消した後の中身で比べる
- 壊れていて読めない画像は、そのまま保存する

### Exifの削除

アップロードの画面の「Exifの削除」をチェックすると、上に加えて次も消す。メディアの「その他の操作」の「Exif削除」とサムネイルの再生成でも同じ。

- JPEG：Exif
- PNG：`eXIf`、`tEXt`、`zTXt`、`iTXt`、`tIME`
- WebP：Exif

Exifの向き（Orientation）も消えるので、縦横が入れ替わって見えることがある（サムネイルも、消した後の画像から作る）。

## 画像のサムネイル

メディアの画像と同じフォルダの`.thumbnail/`に、`元の名前.avif`で作る。ImageMagickでAVIFを書けないサーバーでは、`元の名前.jpg`で作る（`thumbnail_ext`）。

- Exifの向きのとおりに回転し、メタ情報を消してから縮める。sRGBでない写真の色が変わらないように、ICCプロファイルだけは残す
- 長い辺は「編集画面の設定」のサムネイルの大きさ（初期値320px）。それより小さい画像は縮めない
- AVIF：画質80（`album_jpeg_quality`）、4:2:0、エンコードの速度6
- JPEG：画質80、4:2:0、プログレッシブ
- 書き出しはImageMagick（Image::Magick）で行う。avifencなどのコマンドは使わない
- AVIFを書けるかは、小さな画像を実際に書いて確かめる（形式の一覧にあっても、AV1のエンコーダーが無いと書けないため）。AVIFを書けなかった画像は、JPEGで作る
- 画像でないファイルのアイコンと、動画のサムネイル（[動画のサムネイル](動画のサムネイル.md)）はJPEGのまま

前に作ったJPEGのサムネイルが残っていることがあるので、サムネイルを使うときは、今あるものを探す（AVIFを先に見る）。

- 記事：記法`[image:S:...]`の設定（`info/textparser_tags.txt`）は`.jpg`を指す。AVIFがあれば、記法を変換するときにAVIFにする（`Tag_image.pm`の`thumbnail_url`）。サムネイルの形式が変わったら、記事を作り直す
- メディアの一覧：ファイルの一覧（`media/load_image_files`）に、サムネイルのファイル名（`thumb`）を入れて返す
- 編集画面のアイキャッチの候補：AVIF、JPEG、元の画像の順に試す
- サムネイルを作り直すと、ほかの形式の古いサムネイルは消す。ファイルを移動、名前を変更、削除したときは、どの形式のサムネイルも一緒に移動、名前を変更、削除する

## 今ある画像の一括処理

`t/tools/clean_attachments.pl`で、今ある画像のメタ情報を消し、AVIFのサムネイルを作る。CGIでは時間切れになるので、サーバーのコマンドラインで動かす。使い方はスクリプトの先頭に書いてある。

1. `--run`で、原本のメタ情報を消し、AVIFのサムネイルを作る。前のJPEGのサムネイルは残すので、記事はそのまま見られる
2. 管理画面で全記事を再構築する。記事のサムネイルがAVIFを指すようになる
3. `--remove-old`で、JPEGのサムネイルを消す。記事のHTMLがまだ指しているものは消さない

- 何も付けないと、数えて出すだけで何も変えない
- 原本の更新日時は元のままにする。ゴミ箱（`.trashbox`）は触らない
