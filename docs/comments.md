# コメント

データの持ち方は `docs/db-schema.md` の「コメント」を参照。

## 表示

- 記事の下のコメントの欄（`id="com"`、各コメントは `id="cN"`。旧システムと同じ）と、サイドバーの「最近のコメント」（5件）
- 公開側に出すのは `status = 'public'` のものだけ
- 本文（`Lyndbaum::CommentText`）
  - `>>N` は同じ記事のコメント N（`#cN`）へのリンク。記事本文の見出しの ID と重なることはないものとして扱う（自動の ID は `#cN` の形にならない。手で付けた識別子が重なったら記事本文を直す）
  - `http://` `https://` の URL はリンク。リンクの文字は URL をそのまま出し、`rel="nofollow ugc noopener noreferrer"` を付ける
  - 改行と空白はそのまま見せる
- 非公開コメントは扱わない。旧データの非公開コメントも取り込まない

## 設定

管理画面の「コメントの設定」で変える。項目と既定値は`Lyndbaum::CommentSettings`。

| 項目                                           | 既定値                        |
| ---------------------------------------------- | ----------------------------- |
| コメントを受け付ける                           | ON                            |
| すべてのコメントを承認待ちにする               | OFF                           |
| 日本語を含まないコメントを承認待ちにする       | ON                            |
| フォームのトークンをJavaScriptで入れる         | ON                            |
| 連投を制限する                                 | ON（同じIPから10分に3回まで） |
| 長さの決まり                                   | 下の表のとおり                |
| NGワード、拒否するIPアドレス、拒否するホスト名 | 空                            |

- IPアドレスは`192.0.2.10`、`192.0.2.0/24`、`192.0.2.`（前方一致）、`2001:db8::/32`の形。ホスト名は`example.net`と書くと、その下のホストも当たる（`Lyndbaum::AddressMatch`）

## 投稿

- 記事のURLへのPOST（`Lyndbaum::Controller::Comment`）。フォームの欄は`name`、`body`、`token`、`website`（おとりの欄）
- 公開されたら、そのコメント（`#cN`）へ移る。承認待ちなら、記事のページ（`?comment=held`）に「承認待ちです」と出す
- 番号は、その記事で最後に使った番号（`articles.last_comment_num`）の次。消したコメントの番号は使い回さない（旧システムと同じ）。旧データの取り込みでは、取り込まない非公開コメントの番号も含めて最後の番号にする
- 記録するもの：IPアドレス、ホスト名（Webサーバーが`REMOTE_HOST`を渡せばそれ、無ければ逆引き）、UA
  - 逆引きした名前は、正引きして元のIPアドレスに戻るときだけ使う（FCrDNS。逆引きの名前は、そのIPアドレスを持つ人が自由に付けられるため）。戻らなければホスト名は空。2回の問い合わせを合わせて2秒で打ち切る
  - IPv6は逆引きしない（設定していないプロバイダーが多く、関係のない名前が返ることもあるため）。`::ffff:192.0.2.1`の形は、中のIPv4で引く。そのため、拒否するホスト名はIPv4にだけ効く。IPv6はCIDRで拒否する
- 管理者（ログイン中）のコメントは、トークンとおとりの欄だけを確かめ、すぐ公開して管理者の印を付ける。フォームの名前には、管理者が前に使った名前を入れておく
- はじいたときは、理由をWebサーバーのエラーログに残す（`コメントをはじきました（理由）`）

### 承認待ちにするもの

拒否ではなく `held` にする。管理画面で承認すれば公開される。

- URL を含むコメント（悪意のあるリンクやスパムを、承認するまで誰にも見せないため）。`ttp://`のように頭を欠いたものも含む
- NG ワードを含むコメント（語の一覧は設定）。名前と本文を、全角と半角、大文字と小文字、空白の違いを無視して比べる
- 日本語（ひらがな、カタカナ、漢字）を含まないコメント（ON/OFF）
- 承認制を ON にしているときは、すべてのコメント

### はじくもの（理由は返さず、一般的なエラーだけを出す）

何が引っかかったかをボットに教えないため。

- 署名つきの時刻を入れたトークンが無い、署名が合わない、フォームを出してから早すぎる、古すぎる
  - トークンには時刻と記事IDを入れ、`config.json`の`secret_key`で署名する（`Lyndbaum::CommentToken`）。フォームを出してから3秒より早いものと、24時間より古いものをはじく
  - トークンを JavaScript で入れるかどうかは ON/OFF できる（入れると JavaScript を動かさないボットもはじける。その代わり JavaScript を切っている人は投稿できない）
- おとりの欄（人には見えない入力欄）に何か入っている
- 拒否する IP アドレス（前方一致か CIDR）、ホスト名（後方一致）
- 管理者の名前を名乗る投稿（管理者の印は、ログインした管理者のコメントにだけ付く）。管理者の名前は、ログイン名と、これまで管理者として書いたコメントの名前。全角と半角、大文字と小文字、空白の違いは無視して比べる
- 連投の制限（ON/OFF と閾値を設定できる）。そのIPから、期間の中に投稿された件数（承認待ちを含む）で数える

### 理由を書いて返すもの（書いた内容は消さずにフォームへ戻す）

人の書き間違いであることが多いため。

| 項目 | 決まり（既定値。設定で変えられる）  |
| ---- | ----------------------------------- |
| 名前 | 必須、32文字まで                    |
| 本文 | 5文字以上、3,000文字まで、100行まで |

- 文字数はバイト数ではなく文字の数で数える。改行は LF にそろえてから数える
- 前後の空白は取り除く。空白だけなら空として扱う
- 本文の下限は、文字（`\p{L}`）と数字（`\p{N}`）だけを数える（空白や記号を足して通るのを防ぐため）。例：「辿り着きました！」は7文字
- 管理者（ログイン中）のコメントは、本文の下限の対象から外す
