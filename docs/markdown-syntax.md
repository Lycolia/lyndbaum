# Markdown対応記法

記事のMarkdownで使える記法の一覧。旧システム（adiary）で書いた記事のうち、実際に使っている記法に対応する。
パーサー（`lib/Lyndbaum/Parser/`）と、そのテストはこの文書を仕様として扱う。
旧システムの出力と意図的に変えたところは`docs/compat-diffs.md`にある。

## 方針

- CommonMark / GFMのすべては満たさない。**Prettier v3で整形したMarkdownに現れる記法**を基本に、実際に使っている記法だけに対応する。
- 使われていない変則的な記法は切り捨てる。ただし、単純に対応できてPrettierで壊れないものは対応してよい。
- **対応しない記法は、エラーにせず普通の文章として表示する。**例えば`* list`は箇条書きにならず、`* list`という文字のまま出る。

使用数は2026-10-10時点のMarkdown記事745件での数（コードフェンス内は除外）。

#### 見出しのID

```markdown
## 見出し [#l7a712f2]
```

- 見出しの行末に、空白を挟んで`[#識別子]`と書くと、それをIDにする。識別子は画面には出さない。見出しの文字を変えてもIDが変わらず、ページ内リンクや外部からのリンクが壊れない。
  - 識別子には、ASCIIの空白と制御文字、`]`以外の文字を使える（日本語も可）。
  - 見出しの末尾に`[#…]`を文字として書きたいときは`\[#…]`と書く。空白を挟まない`見出し[#…]`も文字になる。
  - 識別子の無い見出しには、保存するときに`l7a712f2`の形（英字1文字と16進数7桁）の識別子を付ける（管理画面で作る）。
  - 旧データの取り込みでは、すべての見出しに、下の規則で見出しの文字から作ったIDを識別子として書き足す（旧システムと同じアンカーを保つため）。
- 識別子が無ければ、見出しの文字から作る。英字は小文字にし、文字と数字以外が続くところは`-` 1つにする（`C#` → `c-`、`見出し ##` → `見出し-`）。
- 同じIDがすでにあれば、`-2`、`-3` … を付ける。
- 見出しは`<a href="記事のURL#ID">`（例：`/0575#見出し`）で自分自身へのリンクにする。目次と脚注（`[n]`と`&#8617;`）のリンクも同じ形。一覧に本文を並べても、ほかの記事の同じIDではなく、その記事の見出しや脚注へ行くようにするため（見出しと目次は旧システムと同じ）。記事のURLが入るので、コンテンツページの名前や親を変えると、そのページと子孫の本文を変換し直す。`base_path`を変えたときは再構築する

#### テーブル

```markdown
| 左寄せ | 中央 | 右寄せ |
| :----- | :--: | -----: |
| a      |  b   |      c |
```

- 各行は`|`で始める。
- 2行目は区切り行（`-`と、位置揃えの`:`）。
- 空行を挟まず、段落やリスト項目の文章の直後から始めてもよい。
- セルは、エスケープしていない`|`で分ける。コードスパンの中の`|`でも分ける。
- セルの中に`|`を書くときは`\|`と書く。コードスパンの中でも`|`として表示する（GFMと同じ）。

### adiary独自の記法

`lib/Lyndbaum/Parser/AdiaryTag.pm`（タグ）と`lib/Lyndbaum/Parser/Common.pm`（目次、続きを読む）で処理する。記法をまたいで使えるよう、Markdownのパーサーとは分けてある。
旧システムのタグのうち、下の表にないものは普通の文章として表示する。

| 記法               | 書き方                                             | 使用数  | 出力                                                                                                                |
| ------------------ | -------------------------------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------- |
| 目次               | `[*toc]`だけの行                                   | 179記事 | 記事の見出しの入れ子の一覧（`<ul class="toc">`）。目次に入る見出しが無ければ何も出さない                              |
| 続きを読む         | `====`または`=====`だけの行                        | ─       | `<!--more-->`。一覧ではこれより前だけを表示する                                                                     |
| 画像アルバムの画像 | `[image:サイズ:フォルダ/:ファイル名:代替テキスト]` | 384記事 | サムネイルを、元の画像へのリンクで囲む（下記）                                                                      |
| YouTube            | `[youtube:動画ID]`                                 | 10記事  | 埋め込みの`<iframe>`                                                                                                |
| URLの埋め込み      | `[&URL]`                                           | 2記事   | YouTubeとニコニコ動画は埋め込みの`<iframe>`。それ以外は、ページのタイトル（保存時に取得したもの）を文字にしたリンク |
| ファイル           | `[file:種類:フォルダ/:ファイル名:説明]`            | 3記事   | `mp4` / `webm`は`<video>`、それ以外はリンク                                                                         |
| バナー             | `[info:文章]` / `[warn:文章]` / `[error:文章]`     | 5記事   | アイコン付きの`<div class="notice_banner 種類">`。段落に囲まない                                                    |

#### 目次

- 見出しの並びを、より浅い見出しを親とする入れ子にする。1段目は`#`の見出し
- 段を飛ばした見出し（`#`の無い`##`、`##`の直後の`####`など）は目次に入れない（旧システムと同じ）
  - 書き方の誤りなので、合わせて直すことはしない。代わりに、`[*toc]`のある記事では、編集の画面と`tools/rebuild-html.pl`の出力で警告する（出力は変えない）

#### 画像

```
[image:S:posts/2026/01/:a.png:代替テキスト]
```

- 画像などの添付ファイルは、設定の`attachment_path`（既定は`/pub/attachments/`）の下に置く。上の例では`/pub/attachments/posts/2026/01/a.png`。
- サムネイルは同じフォルダの`.thumbnail/ファイル名.jpg`。サイズが`L`のときはサムネイルを使わず、元の画像を表示する。
- 代替テキストは書いたとおりに出す。旧システムの画像アルバムは代替テキストにファイル名をそのまま入れていたので、旧データの取り込みで、ファイル名と同じ代替テキストを落とす（`[image:S:フォルダ/:a.png:a.png]` → `[image:S:フォルダ/:a.png]`）。
- 画像の拡大表示（Lythumb）のため、`data-lythumb="k記事ID"`を付ける。
- キャプションは、代替テキストの後の引数に`#`を付けて書く（`[image:S:フォルダ/:ファイル名:代替テキスト:#キャプション]`）。このときは`<figure>`と`<figcaption>`で囲み、画像だけの段落なら`<p>`で囲まない。

## 対応しない記法

いずれも使用数は0。普通の文章として表示する。

| 分類           | 記法                                                                       | 代わりの書き方                           |
| -------------- | -------------------------------------------------------------------------- | ---------------------------------------- |
| 見出し         | 閉じ`#`付き（`## 見出し ##`）                                              | `## 見出し`                              |
| 見出し         | 行頭に空白のあるもの（`  ### 見出し`）                                     | `### 見出し`                             |
| 見出し         | 下線で書くもの（`===` / `---`）                                            | `#` / `##`                               |
| コードブロック | 4スペースのインデントで書くもの                                            | コードフェンス                           |
| コードブロック | `~~~`のフェンス                                                            | ` ``` `                                  |
| コードブロック | 字下げしたフェンス（行頭やリストの項目で、記号の幅より深く字下げしたもの） | 行頭、または項目の内容の開始位置に揃える |
| コードブロック | 数式（` ```math `）                                                        | ─                                        |
| コードブロック | ファイル名の指定（` ```言語:ファイル名 `）                                 | ─                                        |
| 区切り線       | `***` / `___`                                                              | `---`                                    |
| リスト         | `*` / `+`の記号                                                            | `-`                                      |
| リスト         | `1)`形式                                                                   | `1.`                                     |

| テーブル       | 行頭に`\|`の無いもの                                                       | 各行を`\|`で始める                       |
| 強調           | `__太字__`                                                                 | `**太字**`                               |
| 強調           | `***太字斜体***`                                                           | ─                                        |
| リンク         | 参照形式（`[文字][id]`と`[id]: URL`）                                      | `[文字](URL)`                            |
| リンク         | タイトル付き（`[文字](URL "タイトル")`）                                   | ─                                        |

| 改行           | 行末の`\`                                                                  | 不要（段落内の改行は`<br>`になる）       |
| adiary独自     | 注釈`((注釈))`                                                             | 脚注`[^id]`                              |

## テスト

この文書の各項目は`t/markdown/*.txt`のテストケースになっている。

```sh
prove -r t                                  # すべてのテスト
prove t/markdown.t                          # 記法のテストだけ
MD_TEST_FILE=block_list prove t/markdown.t  # 特定のケースファイルだけ
MD_TEST_DUMP=1 prove t/markdown.t           # パーサーの出力を表示する（期待値を作るとき用）
```

- まだ満たせない項目は、ケースに`--- todo:`を付ける（失敗しても全体は成功扱い）。対応したら`--- todo:`の行を消す。
