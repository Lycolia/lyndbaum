# Markdown対応記法

adiaryのMarkdownパーサー（`lib/Satsuki/TextParser/Markdown.pm`）が対応する記法の一覧。
パーサーの作り直しと、そのテストはこの文書を仕様として扱う。

## 方針

- CommonMark / GFMのすべては満たさない。**Prettier v3で整形したMarkdownに現れる記法**を基本に、実際に使っている記法だけに対応する。
- 使われていない変則的な記法は切り捨てる。ただし、単純に対応できてPrettierで壊れないものは対応してよい。
- **対応しない記法は、エラーにせず普通の文章として表示する。**
  - 例えば`* list`は箇条書きにならず、`* list`という文字のまま出る。

使用数は2026-10-10時点のMarkdown記事745件での数（コードフェンス内は除外）。

#### 見出しのID

```markdown
## 見出し [#l7a712f2]
```

- 見出しの行末に、空白を挟んで`[#識別子]`と書くと、それをIDにする。識別子は画面には出さない。見出しの文字を変えてもIDが変わらず、ページ内リンクや外部からのリンクが壊れない。
  - 識別子には、ASCIIの空白と制御文字、`]`以外の文字を使える（日本語も可）。
  - 見出しの末尾に`[#…]`を文字として書きたいときは`\[#…]`と書く。空白を挟まない`見出し[#…]`も文字になる。
  - 識別子の無い見出しには、記事を保存するときに`l7a712f2`の形（英字1文字と16進数7桁）の識別子を付ける。記事の中からその見出しへのリンクがあるときは、リンクが切れるので付けない。
  - 引用の中の見出しには付けない（引用した文章に、元に無いものが入るため）。
  - 旧データ（システムアップデートVer3.53）では、すべての見出しに、見出しの文字から作ったIDを識別子として書き足した（今までと同じアンカーを保つため）。
- 識別子が無ければ、見出しの文字から作る。
- 同じIDがすでにあれば、`-2`、`-3`…を付ける。
- 目次のリンクも同じIDを使う。

#### テーブル

```markdown
| 左寄せ | 中央 | 右寄せ |
| :----- | :--: | -----: |
| a      |  b   |      c |
```

- 各行は`|`で始める。
- 2行目は区切り行（`-`と、位置揃えの`:`）。
- 空行を挟まず、段落やリスト項目の文章の直後から始めてもよい。
- セルの中に`|`を書くときは`\|`とする（コードスパンの中でも）。GFMと同じく`\\|`の`|`はセルの区切りになる。

### adiary独自の記法

adiary独自の記法には、次の2種類がある。

| 種類                                  | 処理する場所                                                         | 扱い                                                                                                                          |
| ------------------------------------- | -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| さつき記法のタグ（`[image:...]`など） | さつき記法パーサー（`Satsuki.pm`）。Markdownパーサーは各行を渡すだけ | タグ一覧（`?etc/satsuki_tags`、定義は`info/textparser_tags.txt`）にあるものはすべて使える。Markdownパーサーの作り直しの対象外 |
| 目次、続きを読む                      | Markdownパーサー                                                     | 下の表のとおり                                                                                                                |

Markdownのインライン処理とタグの処理の順番によっては、タグがMarkdownの記法と取り違えられる恐れがある。作り直しではこの点に注意する。

#### 画像と`<figure>`

Markdownの記事では、画像（`[image:...]`）は段落の中に出力されるため、キャプションが無ければ`<figure>`で囲まない（`<p>`の中に`<figure>`を入れるとHTMLとして不正になるため）。

- キャプションは、画像の後の2つ目以降の引数に`#`を付けて書く（`[image:S:フォルダ/:ファイル名:代替テキスト:#キャプション]`）。このときは`<figure>`と`<figcaption>`で囲む。
- さつき記法など、Markdown以外の記事は今までどおり常に`<figure>`で囲む。
- テーマのchie（画像リンクの装飾）は`<figure>`を前提にしているため、Markdownの記事ではこの効果が無くなる。Lyndbaumテーマは`a[class^="tag-image"]`に余白を指定して対応済み。

#### Markdownパーサーで処理するもの

| 記法       | 書き方                                                                                                                        | 使用数  |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------- | ------- |
| 目次       | `[*toc]`（目次に入る見出しが無ければ何も出さない。段を飛ばした見出しは1つ上の段に繰り上げて出す。引用の中の見出しは入れない） | 179記事 |
| 続きを読む | `====`または`=====`だけの行                                                                                                   | ─       |

| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| 画像アルバムの画像     | `[image:S:フォルダ/:ファイル名:代替テキスト]`                                                                                           | 384記事 |
| 画像へのテキストリンク | `[image:T:フォルダ/:ファイル名:リンクの文字]`（画像ビューアーで開き、リンクの文字をキャプションに出す。リンクの文字を省くとファイル名） | ─       |

## 対応しない記法

いずれも使用数は0。普通の文章として表示する。

| 分類           | 記法                                                                       | 代わりの書き方                           |
| -------------- | -------------------------------------------------------------------------- | ---------------------------------------- |
| 見出し         | 閉じ`#`付き（`## 見出し ##`）                                              | `## 見出し`                              |
| 見出し         | 行頭に空白のあるもの（`  ### 見出し`）                                     | `### 見出し`                             |
| 見出し         | 下線で書くもの（`===` / `---`）                                            | `#` / `##`                               |
| コードブロック | 4スペースのインデントで書くもの                                            | コードフェンス                           |
| コードブロック | `~~~`のフェンス                                                            | ` ``` `                                  |
| コードブロック | 字下げしたフェンス（行頭やリストの項目で、記号の幅より深く字下げしたもの） | 行頭、または項目の内容の開始位置に揃える |
| コードブロック | 数式（` ```math `）                                                        | ─                                        |
| コードブロック | ファイル名の指定（` ```言語:ファイル名 `）                                 | ─                                        |
| 区切り線       | `***` / `___`                                                              | `---`                                    |
| リスト         | `*` / `+`の記号                                                            | `-`                                      |
| リスト         | `1)`形式                                                                   | `1.`                                     |
| リスト         | 字下げせずに前の行に続ける書き方（怠惰な継続）                             | 字下げする                               |
| 引用           | `>`を付けずに前の行に続ける書き方（怠惰な継続）                            | 各行に`>`を付ける                        |
| テーブル       | 行頭に`\|`の無いもの                                                       | 各行を`\|`で始める                       |
| 強調           | `__太字__`                                                                 | `**太字**`                               |
| 強調           | `***太字斜体***`                                                           | ─                                        |
| リンク         | 参照形式（`[文字][id]`と`[id]: URL`）                                      | `[文字](URL)`                            |
| リンク         | タイトル付き（`[文字](URL "タイトル")`）                                   | ─                                        |
| リンク         | 囲まずに書いたURLの自動リンク                                              | `<URL>`か`[文字](URL)`                   |
| 改行           | 行末の`\`                                                                  | 不要（段落内の改行は`<br>`になる）       |

## テスト

この文書の各項目は`t/markdown/*.txt`のテストケースになっている。

```sh
prove t/markdown.t                       # 仕様のテスト
perl t/tools/corpus_diff.pl              # 手元の全記事で、HEADと作業ツリーの出力を比べる
perl t/tools/corpus_diff.pl --diff       # 変わった記事の差分も表示する
```

- 今のパーサーが満たしていない項目は、ケースに`--- todo:`を付けている（失敗しても全体は成功扱い）。対応したら`--- todo:`の行を消す。
- `t/tools/corpus_diff.pl`は記事データ（gitの管理外）を直接読むので、記事の中身はリポジトリに含まれない。
