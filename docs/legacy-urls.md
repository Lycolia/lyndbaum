# 旧URLと転送先

旧システム（adiary）のURLと、新しいURLへの転送（301）の対応。作者から提供された実際のURLの例をもとにしている。

## 記事とコンテンツページ

旧システムと同じURLなので、転送しない。パスは記事の `slug`（旧 `link_key`）と同じ。

| URL                            | 内容                                     |
| ------------------------------ | ---------------------------------------- |
| `/0575`                        | 記事（slug は `0` + 記事ID）             |
| `/管理人について/保有デバイス` | コンテンツページ（slug は 0 で始めない） |

記事内の相対リンク（`[文字](0618)`、`[文字](管理人について#概要)`）は、先頭に `/` を付けて slug へのリンクにする（旧システムと同じ）。

## トップページのクエリ

旧システムでは、一覧の絞り込みはすべてトップページ `/` へのクエリで行う。

| 名前  | 意味                                                                  | 例                 |
| ----- | --------------------------------------------------------------------- | ------------------ |
| `t`   | タグ。親を含めた名前（`::` 区切り）。複数指定するとすべてを満たす記事 | `t=言語::C%23.NET` |
| `d`   | 年月（`YYYYMM`）                                                      | `d=202609`         |
| `q`   | 検索語                                                                | `q=aaa`            |
| `all` | 検索の範囲。`0` か無しならタイトル、`1` なら全文（原文を探す）        | `all=1`、`all=0`   |
| `p`   | ページ番号                                                            | `p=2`              |

クエリの先頭に空の項目が付くことがある（`/?&t=…`）。

開発用の旧システム（https://adiary.lycolia.info/）で、出力から次のことを確かめた（2026-10-14）。

- `all=0` はタイトル、`all=1` は全文を探す。全文は Markdown の原文を探している（`](` で当たる）。`all` が無いとタイトルと同じ結果になる
- 検索語は大文字と小文字を区別しない。空白（全角を含む）で区切った語は、すべてを含む記事を探す。`-語`、`OR`、`"…"` は文字そのものとして探す
- `t` を複数指定すると、すべてのタグが付いた記事。親のタグは子孫のタグを含む。`t=`（空）はタグの無い記事
- `d` は年（`YYYY`）か年月（`YYYYMM`）。不正な値は無視する
- コンテンツページも検索の対象になる

作者から提供された例：

```
タグ1つ           /?&t=%E8%A8%80%E8%AA%9E::C%23.NET
タグ複数           /?&t=OS::Linux::Ubuntu&t=ジャンル::自宅サーバー&t=ソフトウェア::CMS
タグと日付         /?&t=OS::Linux::Ubuntu&t=ジャンル::自宅サーバー&d=202609
タグと日付と検索語 /?all=0&q=aaa&t=OS%3A%3ALinux%3A%3AUbuntu&t=ジャンル%3A%3A自宅サーバー&d=202609
ページ送り         /?&p=2
検索               /?q=aaa&all=1
年月               /?d=202606
```

| 旧URL                                             | 転送先                            | 状態                                                        |
| ------------------------------------------------- | --------------------------------- | ----------------------------------------------------------- |
| `/?p=2`                                           | `/?page=2`                        | 対応済                                                      |
| `/?t=言語::C%23.NET`（1つ）                       | `/search?t=言語::C%23.NET`        | 対応済（p の併用も可）                                      |
| 上記以外（複数タグ、タグなし `t=`、日付、検索語） | `/search?q=…&in=…&t=…&d=…&page=…` | 対応済。`all=1` は `in=source`、`all=0` と無しは `in=title` |

存在しないタグを指定した旧URLは404にする。
