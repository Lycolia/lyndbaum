# コメントのスパム対策

Lyndbaum（`~/develop/perl/lyndbaum`の`docs/comments.md`）の決まりを、adiaryの本体（`post_comment`）に移したもの。

## 対象

- 管理者のコメントは、すべての判定の対象外（今のコメント保留と同じ）
- ログインしているそれ以外の人は、おとりの欄と、本文の上限だけを確かめる
  - トークンは確かめない。ログインできる人はボットではないため（フォームにはログイン中でもトークンが入る）
  - 名前はログイン名に決まるので確かめない

## はじくもの

理由は返さず、`Comment post failed. Please reload the page and try again later.`だけを出す（何が引っかかったかをボットに教えないため）。理由はWebサーバーのエラーログに`コメントに失敗しました（理由）`の形で残す。

| 理由         | 内容                                                                                            |
| ------------ | ----------------------------------------------------------------------------------------------- |
| `token`      | トークンが無い、署名が合わない、別の記事のもの、フォームを出してから3秒より早い、24時間より古い |
| `honeypot`   | おとりの欄（`website`。人には見えない入力欄）に何か入っている                                   |
| `blocked_ip` | 拒否するIPアドレスに当たる                                                                      |
| `rate_limit` | 同じIPアドレスから、期間の中に投稿された件数（承認待ちを含む）が上限に達している                |

### トークン

- 形は`v1.記事番号.発行した時刻.署名`。署名は、それより前の部分を、システムの`Secret_word`でHMAC-SHA256にしたもの（base64url）
- 今までどおり`data-secure`に隠して置き、JavaScriptで入れる。JavaScriptを切っている人は投稿できない

#### 投稿ボタンが押せるようになるまで

記事を編集できる人（ブログ管理者と編集者）以外は、ページを開いた時点で投稿ボタンを押せなくしておき（`disabled`）、次のどちらかが起きたときに、トークンをフォームに入れてボタンを押せるようにする（`pub/assets/js/adiary.js`の「セキュリティコードの設定」）。

| 条件                         | 値（`pub/assets/js/adiary.js`）       |
| ---------------------------- | ------------------------------------- |
| 本文の欄で、キーを10回押した | `CommentEnableKeys = 10`              |
| ページを開いてから10秒たった | `CommentEnableTime = 10000`（ミリ秒） |

- ページを開いてすぐ送ってくるボットと、JavaScriptを動かさないボットをはじくため。用意した文面を貼り付けてすぐ送る、人の手のスパムにも効く。サーバー側でも、トークンを出してから3秒より早い投稿をはじく
- 数えるのは本文の欄（`textarea`）の`keydown`だけ。名前の欄への入力、マウスでの貼り付け、スマホの予測変換や音声入力などは数えられないことがあり、その場合は10秒たつまで押せない
  - そのため「書いたのに投稿ボタンが押せない」ことがあるが、不具合ではない。ボタンのヘルプにも「押せない時は少しお待ちください」と書いてある
- 記事を編集できる人は待たせない。テンプレートが、その人にだけコメントフォームに`data-no-wait="1"`を付け、JavaScriptはそれを見てボタンをそのまま押せるようにする（サーバー側でも、スパム対策の判定の対象外）
- それ以外のログインしている人は、ログインしていない人と同じく待たせる（サーバーがログイン中の人のトークンを確かめないだけ）

### 拒否するIPアドレスの書き方

1行に1つ。

| 書き方                          | 当たるもの                 |
| ------------------------------- | -------------------------- |
| `192.0.2.10`、`2001:db8::1`     | そのアドレスだけ           |
| `192.0.2.0/24`、`2001:db8::/32` | CIDRの範囲                 |
| `192.0.2.`、`2001:db8:`         | 前方一致（末尾が`.`か`:`） |

書き方の正しくない行があれば、設定を保存しない。

ISP単位のBANくらいにしか使えないためホスト名での拒否は作らない。

## 理由を書いて返すもの

書いた内容は消さずにフォームへ戻す（人の書き間違いであることが多いため）。

| 項目 | 決まり（既定値）                                                                   |
| ---- | ---------------------------------------------------------------------------------- |
| 名前 | 必須、32文字まで、登録ユーザーの名前と同じ名前や、管理者と紛らわしい名前は使えない |
| 本文 | 必須、5文字以上（文字と数字だけを数える）、3,000文字まで、100行まで                |

- 文字数はバイト数ではなく文字の数で数える。改行はLFにそろえ、前後の空白を除いてから数える
- 本文の下限は、文字（`\p{L}`）と数字（`\p{N}`）だけを数える（空白や記号を足して通るのを防ぐため）
- 登録ユーザーの名前との比較は、全角と半角、大文字と小文字、空白の違いを無視する。理由を出すので、その名前が登録ユーザーのものだと分かるが、名前は記事の投稿者などとして公開されているので、問題にしない
- IDとは比べない。なりすましで困るのは表に出る名前のほうで、IDと比べて理由を出すと、その文字列がログインのIDだと分かってしまうため
- 管理者と紛らわしい名前は、記号と空白を除いてから比べる（`is_admin_like_name`）
  - 英語は、名前全体が`admin`、`administrator`、`administrater`、`sysadmin`、`sysop`、`root`、`webmaster`、`moderator`、`owner`のどれかのとき。後ろの数字は無視する（`admin1`もはじく）。`badminton`などをはじかないよう、含むだけでははじかない
  - 日本語は、名前に「管理人」「管理者」「運営」を含むとき（「ブログ管理人です」などもはじく）
- 管理者が書いたコメントには、名前の後ろに「管理者」の印（`comment-badge`）を付け、`comment-one`に`comment-admin`のクラスを付ける。名前だけでは見分けられないため
  - 管理者は`_users`にあるユーザー
  - コメントを書いた時のIDで判定するので、後で管理者でなくなった人のコメントからは印が消える
  - ブログの管理者がコメントのフォームを開くと、名前の後ろに同じ印が出る
- ログインしている人は、本文の上限と行数だけを確かめる

## 承認待ちにするもの

拒否ではなく保留（`enable=0`）にする。管理者が「表示に設定」すれば公開される。ログインしている人は対象外。

- URLを含むコメント（ON/OFF）。名前と本文の`http://`、`https://`（`ttp://`のように頭を欠いたものも含む）と、URL欄に値があるもの
- NGワードを含むコメント。名前と本文を、全角と半角、大文字と小文字、空白の違いを無視して比べる
- 日本語（ひらがな、カタカナ、漢字）を含まないコメント（ON/OFF）
- すべてを保留にする設定は、今の「コメント保留」（`defer_com`）をそのまま使う

## 設定

ブログの設定の「コメント保留」の下。値が空のときは既定値を使う。

| キー                                               | 内容                                           | 既定値         |
| -------------------------------------------------- | ---------------------------------------------- | -------------- |
| `com_hold_url`                                     | URLを含むコメントを承認待ちにする              | ON             |
| `com_require_ja`                                   | 日本語を含まないコメントを承認待ちにする       | ON             |
| `com_rate_count` / `com_rate_min`                  | 連投の制限（回数/期間の分）。回数0で制限しない | 3 / 10         |
| `com_name_max`                                     | 名前の文字数の上限                             | 32             |
| `com_body_min` / `com_body_max` / `com_body_lines` | 本文の文字数の下限/上限/行数の上限             | 5 / 3000 / 100 |
| `com_ng_words`                                     | NGワード（1行に1つ）                           | 空             |
| `com_block_ips`                                    | 拒否するIPアドレス（1行に1つ）                 | 空             |

## 表示

- コメントのURL欄のリンクには`rel="nofollow ugc noopener noreferrer"`を付ける
