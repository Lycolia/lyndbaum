###############################################################################
# デフォルトパーサー用 ユーザー独自タグ定義ファイル
###############################################################################
#　・先頭 '#' はコメント。空行は無視。
#　・alias は ">linkname"。１階層しかたどれない。
#　・url には「,」を含めない。
# （参考）http://adiary.blog.abk.nu/066
#-----------------------------------------------------------------------------
# サンプル
#-----------------------------------------------------------------------------
#npm            = npmのパッケージ,     ASCII, 1, https://www.npmjs.com/package/$1
#github#2       = GitHubのリポジトリ,  ASCII, 2, https://github.com/$1/$2
#
# エイリアス（別名）
#n            = >npm
#
# タグ置換
#kbd   = キー入力, ASCII, 1, <kbd>#1</kbd>
#
# HTMLタグ置換
#bf    = html:strong
#pre   = html:span.pre
#[pre:xxx] → <span class="pre">xxx</span>
#-----------------------------------------------------------------------------
